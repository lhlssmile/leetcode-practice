# 水平梯形计数问题 - 公式法详解 🎯

## 问题描述
给定二维平面上的点集，计算能组成**水平梯形**的四点组合数量。

**水平梯形**：至少有一对水平边（平行于x轴）的凸四边形。

## 🤔 为什么要枚举两个不同的y值？

### 核心思想
水平梯形的关键特征是**至少一对水平边**，这意味着：
- 至少有两个点的y坐标相同（构成一条水平边）
- 需要另外两个点构成另一条边（可以是水平边或斜边）

### 数学建模
```
梯形示例：
    A ——————— B  (y = y2)
   /           \
  /             \
 C ——————————— D  (y = y1)
```

要构成水平梯形，我们需要：
1. **上边AB**：两个点在同一水平线 y = y2
2. **下边CD**：两个点在同一水平线 y = y1
3. **y1 ≠ y2**：两条水平边在不同高度

## 🧮 公式法推导

### 步骤1：按y坐标分组
```cpp
map<int, vector<int>> yGroups;
for (auto& point : points) {
    yGroups[point[1]].push_back(point[0]);
}
```

假设我们有：
- y = 0: [1, 2, 3] （3个点）
- y = 2: [2, 3] （2个点）

### 步骤2：枚举两个不同y值
```cpp
for (int i = 0; i < yCounts.size(); i++) {
    for (int j = i + 1; j < yCounts.size(); j++) {
        // 计算梯形数量
    }
}
```

**为什么是两个不同的y值？**
- 梯形需要**两条水平边**
- 每条水平边由**同一y值上的两个点**构成
- 两条水平边必须在**不同高度**（y1 ≠ y2）

### 步骤3：组合数学计算
对于两个y值组：
- 第一组有 n1 个点 → 可选择 C(n1, 2) 种点对
- 第二组有 n2 个点 → 可选择 C(n2, 2) 种点对
- 总梯形数 = C(n1, 2) × C(n2, 2)

```cpp
long long count1 = (long long)n1 * (n1 - 1) / 2;  // C(n1, 2)
long long count2 = (long long)n2 * (n2 - 1) / 2;  // C(n2, 2)
result += count1 * count2;
```

## 📊 具体例子

### 示例：points = [[1,0],[2,0],[3,0],[2,2],[3,2]]

**分组结果：**
- y = 0: [1, 2, 3] （3个点）
- y = 2: [2, 3] （2个点）

**计算过程：**
1. 从 y=0 选2个点：C(3,2) = 3种方式
   - (1,0) + (2,0)
   - (1,0) + (3,0) 
   - (2,0) + (3,0)

2. 从 y=2 选2个点：C(2,2) = 1种方式
   - (2,2) + (3,2)

3. 总梯形数：3 × 1 = 3

**验证：**
- 梯形1：(1,0)-(2,0)-(2,2)-(3,2) ❌ 不是梯形
- 梯形2：(1,0)-(3,0)-(2,2)-(3,2) ✅
- 梯形3：(2,0)-(3,0)-(2,2)-(3,2) ✅
- 实际上还有一个：(1,0)-(2,0)-(3,2)-(2,2) ✅

## 💡 关键洞察

### 为什么枚举两个不同y值？
1. **几何约束**：梯形必须有两条平行边在不同高度
2. **计数简化**：避免复杂的几何判断，直接用组合数学
3. **效率优化**：O(k²) 复杂度，其中k是不同y值数量

### 公式法的优势
- **简单直观**：核心就是组合数学 C(n1,2) × C(n2,2)
- **高效计算**：避免O(n⁴)的暴力枚举
- **易于理解**：将几何问题转化为计数问题

## 🔧 完整代码实现

```cpp
int countTrapezoidsFormula(vector<vector<int>>& points) {
    const int MOD = 1e9 + 7;
    
    // 按y坐标分组
    map<int, vector<int>> yGroups;
    for (auto& point : points) {
        yGroups[point[1]].push_back(point[0]);
    }
    
    long long result = 0;
    vector<int> yCounts;
    
    // 收集每个y值的点数
    for (auto& [y, xs] : yGroups) {
        yCounts.push_back(xs.size());
    }
    
    // 枚举两个不同的y值
    for (int i = 0; i < yCounts.size(); i++) {
        for (int j = i + 1; j < yCounts.size(); j++) {
            // 梯形数量 = C(n1,2) * C(n2,2)
            long long count1 = (long long)yCounts[i] * (yCounts[i] - 1) / 2;
            long long count2 = (long long)yCounts[j] * (yCounts[j] - 1) / 2;
            result = (result + count1 * count2) % MOD;
        }
    }
    
    return result;
}
```

## 🎯 总结

公式法的核心思想：
1. **水平梯形 = 两条不同高度的水平边**
2. **枚举所有y值对 = 枚举所有可能的水平边组合**
3. **组合数学 = 高效计算每种组合的数量**

这就是为什么要枚举两个不同y值的原因：**每个y值代表一条潜在的水平边，两个不同y值组合就能构成一个梯形的框架！** 🎉
