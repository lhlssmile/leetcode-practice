# 教教我递归和递推的区别喵？

## 递归 vs 递推的核心区别

### 1. **思维方式不同**
- **递归**：自顶向下，从大问题分解到小问题
- **递推**：自底向上，从小问题构建到大问题

### 2. **执行顺序不同**
- **递归**：`dfs(n-1)` → `dfs(n-2)` → ... → `dfs(0)` → 回溯计算
- **递推**：`f[0]` → `f[1]` → ... → `f[n+1]` 顺序计算

### 3. **代码实现对比**

```cpp
// 递归 - 记忆化搜索
class Solution {
public:
    int rob(vector<int>& nums) {
        int n = nums.size();
        vector<int> memo(n, -1); // -1 表示没有计算过

        // lambda 递归函数
        // dfs(i) 表示从 nums[0] 到 nums[i] 最多能偷多少
        auto dfs = [&](this auto&& dfs, int i) -> int {
            if (i < 0) { // 递归边界（没有房子）
                return 0;
            }
            if (memo[i] != -1) { // 之前计算过
                return memo[i];
            }
            return memo[i] = max(dfs(i - 1), dfs(i - 2) + nums[i]);
        };

        return dfs(n - 1); // 从最后一个房子开始思考
    }
};
```

**递归版本的亮点：**
- 状态定义直观：`dfs(i)` 表示从 `nums[0]` 到 `nums[i]` 最多能偷多少
- 记忆化剪枝避免重复计算
- 思路清晰：要么偷当前房子，要么不偷

```cpp
// 递推 - 动态规划
class Solution {
public:
    int rob(vector<int>& nums) {
        int n = nums.size();
        vector<int> f(n + 2);  // 巧妙！多开2个位置避免边界判断
        for (int i = 0; i < n; i++) {
            f[i + 2] = max(f[i + 1], f[i] + nums[i]);
            //     ↑         ↑        ↑
            //   当前状态   不偷i    偷i
        }
        return f[n + 1];  // 最终答案
    }
};
```

**递推版本的技巧：**
- `vector<int> f(n + 2)` 避免边界判断
- 状态转移清晰：`f[i+2] = max(f[i+1], f[i] + nums[i])`
- 空间可进一步优化到 O(1)

### 4. **性能对比**

| 方法 | 时间复杂度 | 空间复杂度 | 优缺点 |
|------|------------|------------|--------|
| 递归 | O(n) | O(n) 记忆化 + O(n) 栈 | 思路直观，但有栈溢出风险 |
| 递推 | O(n) | O(n) DP数组 | 效率高，可优化空间 |
| 递推优化 | O(n) | O(1) | 最优解，生产环境首选 |

### 5. **空间优化版本**

```cpp
// 递推 - 空间优化到 O(1)
class Solution {
public:
    int rob(vector<int>& nums) {
        int f0 = 0, f1 = 0;  // 只需要前两个状态
        for (int x : nums) {
            int new_f = max(f1, f0 + x);
            f0 = f1;
            f1 = new_f;
        }
        return f1;
    }
};
```

### 6. **什么时候用哪个？**

**用递归当：**
- 问题有明显的子问题结构
- 状态转移不明显，需要"试探"
- 面试时想展示思维过程
- 树形DP、区间DP等复杂场景

**用递推当：**
- 状态转移清晰
- 对空间/性能有要求
- 生产环境（避免栈溢出）
- 线性DP、背包DP等经典场景

### 7. **核心洞察**

1. **递归 = 分治思想**：把大问题分解成小问题
2. **递推 = 构造思想**：从已知构造未知
3. **记忆化 = 递归优化**：避免重复计算
4. **空间优化 = 递推精髓**：只保留必要状态

> 💡 **记忆口诀**：递归想分解，递推想构造；递归易理解，递推更高效！
